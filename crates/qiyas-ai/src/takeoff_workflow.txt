Take-off workflow:
For quantity jobs only, work from drawing evidence in any language/units, respecting the approval mode. Record uncertainty; do not turn drawing jobs into take-off.
1. Start with qiyas_execute plan: stable ids, pending/active/done/skipped. Each phase is one user-recognisable goal with its proof in the title. Examples: read drawing (sheets, units, scale, layers); one family's types and recognition; method; BOQ mappings; check nothing unmeasured/unmapped; final report. On large projects split families by level/sheet. Read digest then takeoff_kit; its per-phase batches are examples, not scope. Do not rediscover contracts in the kit.
2. Work ONLY the active phase. Execute small batches for that goal: at most 12 commands (many objects of one family count as one). Types and recognition for one family may share a batch; method, mappings and report are separate phases. After the last edit, check with takeoff_check (offset pages), measurement.report summary, records with fields, or explain a sample item. Fix findings and recheck before marking done. After three failed attempts, mark skipped with the reason in its title and continue. Never claim skipped work complete. "Continue" resumes the active phase of the open plan, preserving ids.
3. Reads stay small: detail: summary, selected fields and artifact pointers. Never detail: full on measurement results or whole artifacts. Read extra digest pages only for omitted scope. If needed capture a suggested picture; read legends, schedules and documents. Never guess handles from pictures.
4. Every drawn element is in scope unless the user narrowed it: give each a type, measurement rule and mapping. Use geometry.length/area/count; aliases cannot reference themselves. Raw regions, lines and counts are candidates until recognised and mapped. Cite define_check rules when supported. Name term factors (factor_labels, chat language); cite values via sources on place_objects/set_object_props and source_kind/handle on constants. Net geometric quantities have no waste/allowance unless a note names it. Never type quantities or rates.
5. measurement.set_mappings generates BOQ; measurement.report reads it and dimensions. Preserve the selected method; project override wins. For a named standard without saved rules, write your own rules via measurement.set_method at the kit's scope, citing "<standard> clause <n>". Reuse saved rules. Never copy standards or invent clauses; report uncertain rules/references. Without a method, adapt the kit's cited geometric method and say geometric. Declare kind (count/length/area/volume), basis (geometric or rule:<cited note name>); BOQ codes are not bases. Before factors, read relevant notes, nearby handles and schedules using fields/pointers; proximity proves nothing. Measure named_handles with their factors, only on named items. Counts are whole numbers. Keep base count, length, area or volume from stated depth separate; each factor/allowance gets another rule. "Plus N%" means total including addition. Check percentage factors against the stated basis.
6. Run check for imported items and cited checks; takeoff_check uses evidence-based verify expectations. Fix fractional counts, global allowances, omitted named_handles and factors on disjoint handles. Correct by handle; recognition.review accepts, fixes or rejects uncertain matches. Never accept missing evidence for coverage. Check all unmeasured_elements and unmapped_quantities; evidence shares do not prove completeness.
7. End with generated BOQ, method, unresolved evidence and affected items. Exclude a named handle only with its note: Exclude <handle>: <reason> (note <handle>). Pass the draft answer as takeoff_check.end_report; retain exclusion lines in the final answer/finish.answer. At budget notices, stop exploring and complete supported phases; disclose skipped work. Unfixed errors prevent claiming completion.
Scans: installed text reading returns marked OCR. Empty text/vectors do not mean empty scope. Capture the digest's path/page; calibrate from visible dimensions/scale bar. recognition.vision takes verbatim labels with positions, calibration_spans, dimensions (text, endpoints, metres_per_unit). Use the longest reference; disclose residual uncertainty above 0.5%, failures and missing evidence.
Revision: open B, use takeoff_kit.revision. carry_knowledge from A reapplies recognition on every sheet, retaining A quantities/identities. Re-take-off phase by phase with carried method/mappings; repair from B evidence, then variation_report creates quantities and clouds.
Project: takeoff_kit.project lists/opens or creates a project and adds supplied drawings. Paths: qiyas_dir()/projects. Open each member, interpret phase by phase, apply project method override, save its knowledge. Continue across drawings. Cite project.set_checks with explicit drawing selectors/table.drawing paths; project.set_register_rules uses observed title-block tags/text. project.run aggregates quantities, traces and checks, exports workbook/report. Report failed drawings and register fields. Coincident floors are not duplicates.
Rooms: boundary_layers/exclude_layers follow enclosure evidence, excluding annotations, grids and opening symbols. Labels use Area / المساحة with Arabic digits in Arabic; approval stays in the report.
Before comparing, link measurements with link_boq or matching names. Notes belong in answers or drawing text (values, never ids), never BOQ rows. Describe types/sizes ({mark}, {width}); gross floor area is informational: true. Tag openings with object_tags {category: opening, property: mark}. Fix warnings. Save only when asked; finish never saves.
Before take-off, run qiyas_read run measurement pack_check and show its card; fix/state failures. Compare/export use blind second reading; differing items become drawing queries. After BOQ export, export_evidence in the same language; report both paths.
Walls use joined geometry.volume (junctions counted once, openings cut), geometry.internal_face_area and geometry.external_face_area as three separate BOQ items. No manual void deductions or length × width × height or length × height × 2.
