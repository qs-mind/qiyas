# AI evaluation lessons

- 2026-10-15: A scripted provider can prove tool execution and reference quantities. It cannot prove model understanding or live API acceptance. Keep real drawing reference answers independent of Qiyas output. A 400 response without the rejected request body does not establish a root cause.
- 2026-10-15: Keep real-drawing reference manifests outside the repository. Calculate answers from endpoints and record source hashes. A shared DWG decoder limits the claim to independent arithmetic; professional approval is a separate gate.

- 2026-10-15: Record professional reference acceptance with its exact scope and interaction ID. Shared-decoder endpoint arithmetic supports geometry tool tests only; it does not establish construction quantities or live model accuracy.

- 2026-10-15: Before final review, match private source hashes and bind the review to file hashes. Reuse recorded test results when only reference acceptance changes; keep the technical review separate from live model and release gates.

- 2026-10-15: Close a local evaluation task after the saved technical approval and a matching source snapshot. Reuse accepted test results; keep live model accuracy, original API failure diagnosis, and release approval outside that closure.

- 2026-10-15: Keep INSERT-record scope in empty results, saved measurements and exports. A geometric region cannot prove professional wall faces or approved net area. Preserve legacy basis as unspecified and test absolute, relative and integer verdicts separately.

- 2026-10-15: After source review approval, verify the accepted file hashes and hand the same patch and evidence map to the existing desktop test issue. Close the implementation scope; desktop acceptance and release remain separate.

- 2026-10-15: Candidate labels need an explicit request language because the seed name and UI can differ. Language changes must preserve unapproved_net and net_accuracy_eligible=false.

- 2026-10-15: A language-label handoff must use the reviewed source hashes and test opposite-language seed names in Tauri. Link the desktop wait to the tester task; an answered source review is no longer a waiting path.

- 2026-10-15: If the tester created the implementation issue, delegation_cycle prevents a child back to that tester. Hand the accepted patch to the existing tester issue and preserve its blockers.
