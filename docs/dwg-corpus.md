# DWG compatibility corpus

This check opens real public DWG files for R2000, R2004, R2007, R2010,
R2013 and R2018, plus a DXF. These are LibreDWG's `example_<year>`
test drawings, not files generated by Qiyas. The source revision is
`f860b0fb76d5f8effb5a70769a3389cb1e0308c8`:
https://github.com/LibreDWG/libredwg/tree/f860b0fb76d5f8effb5a70769a3389cb1e0308c8/test/test-data

The runner downloads the drawings into a cache outside this repository.
Qiyas does not redistribute those bytes or include LibreDWG as a dependency.
No customer drawings are committed. Each public result records its URL,
SHA-256, size and header version check. Keep the cache for repeat runs.

```sh
CARGO_BUILD_JOBS=2 cargo build -p qiyas-core --example corpus_open --example corpus_fixtures
python3 scripts/dwg_corpus.py --cache /path/outside/repo/corpus --output report.json
```

Add `--local /private/drawing.dwg` for a local customer drawing. The JSON
uses an anonymous label and omits its path, name and warning text. The
probe opens the input without saving it.
The runner also generates two temporary DXF hosts. One has a missing xref;
the other has a missing image. Both must open with the expected warning.
The generator accepts a new directory only. All generated files are removed
when the check ends.

Each drawing runs in a fresh process. `open_ms` includes `Session::open`;
`ready_ms` also includes the first render batch (CPU, without a GPU window).
`peak_rss_kib` is the peak resident memory from `getrusage(RUSAGE_CHILDREN)`
in a fresh Python process with one probe child. It includes rendering and
JSON output. This is a Linux measurement. The default dev
profile optimises dependencies and geometry/render crates; it is not a
release installer benchmark. The runner has a 60-second timeout per file.
Do not equate these results with AutoCAD verification or complete rendering.

The report includes skipped records and all reader warnings. An opened file
with skipped data must be reviewed before claiming full compatibility.
The public corpus must retain 211 entities, 194 render ranges, five layers,
and three sheets. All DWG versions must produce 22,672 line segments.
The DXF produces 22,751 segments. Its segment count can differ in this check.
(11,767 and 11,846 until 2026-10-19, when a circle got 16 segments at least: the corpus's small
circles had as few as 4. See `docs/2026-10-19-qiyas-units-mizan-check.md`.)
These counts check consistency across formats. They do not prove that every
element has the same appearance in AutoCAD.
The runner returns a failure if a drawing cannot open or a missing-reference
warning is absent. The separate
`under_5_seconds` value on a private drawing checks opening plus first batch.
An exceeded time limit also makes the runner return a failure.

Missing-reference regression checks already create and save real DXF hosts,
remove the referenced file, then reopen and inspect the warning and batch:

```sh
cargo test -p qiyas-core --test xref a_missing_xref_is_listed_with_the_paths_tried_and_the_host_still_opens
cargo test -p qiyas-core --test image a_missing_image_file_is_a_problem_and_draws_nothing
cargo test -p qiyas-core --test open
```

These tests check that the host opens, that missing content is identified,
and that missing content does not appear as drawn geometry. The image test
also checks recovery when the image is found in an `images/` directory.
