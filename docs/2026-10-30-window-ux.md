# إصلاحات نافذة قياس، 30 أكتوبر 2026

## التغييرات حسب بنود المهمة

1. أسئلة ميزان تظهر سؤالًا واحدًا في كل خطوة، مع تقدم ورجوع وتالي وإرسال. الاختيار أو النص شرط للتقدم، والإرسال يجمع الإجابات المرقمة في رسالة واحدة بنفس `answerText`. الأسهم تختار، و Enter يتقدم أو يرسل. الإجابة المكتوبة تخص سؤالها، والإرسال المكرر ممنوع أثناء الطلب. الحالة محفوظة خلال إعادة العرض، والرد المقبول أو المحادثة المستعادة يظهران كملخص للقراءة فقط. أزيل مسار إرسال اختيارات الأسئلة من الـ Composer.
2. اختفت خانة «إجابة أخرى» الوهمية، وتُستبعد تسميات الخيارات التي لا تحتوي إلا على تعليمات كتابة إجابة بالعربية أو الإنجليزية. لكل سؤال حقل حقيقي، حتى عندما لا توجد خيارات. الخيار الموصى به يظل مميزًا كما كان.
3. التنبيهات العادية والانتظار والخطأ والتراجع تستخدم `toast.custom` وبطاقة واحدة. خط التطبيق وحوافها ومسافاتها وارتفاعها الأدنى موحدة، وزر إغلاق `ib` في نهاية الصف المنطقية وبمنتصف ارتفاعه. الخطأ يحتفظ بعلامة لون التحذير، ولا توجد أيقونة أو زر إغلاق افتراضي من Sonner. مدد العرض والتكديس وعدّاد التراجع محفوظة.
4. تحديث الخلفية يتجاوز ازدحام قفل الرسم ويعيد المحاولة عند التغيير التالي؛ الأخطاء الحقيقية تظل ظاهرة. الحفظ التلقائي لا يعطّل نفسه بسبب الازدحام. المحاولة اليدوية المرفوضة تعرض تنبيهًا واحدًا بمعرّف ثابت وباللغة الحالية، وزر إيقاف يستهدف الرسم الذي صدر منه التنبيه. تحديث العرض لا يلغي عرض التراجع، لكن تعديلًا فعليًا من ميزان أو MCP يلغيه.
5. زر آخر الرسائل يعتمد فقط على وجود محتوى زائد ومسافة أكبر من 32 px من النهاية، مع إعادة القياس عند التمرير وتغير المحتوى وتغير الحجم. نية الصعود توقف المتابعة التلقائية فقط. الزر في صف محجوز خارج النص، و `t("ai.jumpLatest")` مع لغة واتجاه الواجهة صراحة.

## مراجعة مسارات الخلفية

| المسار | النتيجة |
|---|---|
| معلومات الرسم والطبقات والتبويبات | تستخدم البيانات المنشورة بالفعل؛ أحداث ميزان و MCP أصبحت تستخدم مسار تحديث الخلفية |
| إعدادات الرسم والكميات والمجاميع و BOQ والتعارضات و paper views | مسار `cached_read` الموجود محفوظ |
| named views | تُنشر مع البيانات وتُقرأ عند ازدحام القفل؛ نفس JSON المرسل للنافذة |
| measurement report | آخر تقرير مقروء بنجاح متاح أثناء القفل؛ أول قراءة بلا نسخة سابقة تتجاوزها الواجهة بهدوء |
| تحديث الخصائص و entity info والصور المحددة والقيود | مسارات الواجهة الموجودة تلتقط فشل القراءة بهدوء وتُقرأ مجددًا مع تغير الرسم |
| التحويم والالتقاط | snap أثناء التحويم يخرج من حلقة الانتظار، ويتجاوز `useTool` الازدحام بهدوء ثم يحاول عند حركة المؤشر التالية. الالتقاط الصريح يظل ينتظر على الرسم الأصلي |
| batches و atlas و glyphs و underlays و split view | النسخ الموجودة متاحة؛ تحديثات العرض والكشف والصور والنافذة المقسومة تتجاوز الازدحام دون تنبيه |
| pack check و recognition queue | تجاوز ازدحام القراءة التلقائية، ثم إعادة المحاولة عند تغير revision أو الحالة |
| الحفظ التلقائي و file watch و recovery | الحفظ الجانبي لا يعطّل نفسه؛ مراقبة الملفات و autosave_workspaces تتجاوز الرسم المقفول بالفعل. قراءة الاسترداد والتبويبات التلقائية تتعامل مع الفشل بهدوء |
| close_tab و sheet_set_from_tabs و project_command و ai_send | إجراءات صريحة وليست polling؛ لم تُزل قيود القفل أو الملكية منها |

التحديث النهائي عند حدث `end` يعيد قراءة البيانات بعد انتهاء ميزان. نسخة التقرير قد تتأخر أثناء عملية طويلة، ولا تُستخدم لتنفيذ تعديل. لم تتغير قرارات ميزان أو قواعد التصميم أو أي ملف من ملفات core التابعة للشغل الآخر.

## الاختبارات والتغييرات عليها

- `QuestionList.test.tsx`: اختبارات الخطوات والرجوع وإعادة العرض والنص الخاص بكل سؤال، وتنقية تعليمات الكتابة باللغتين، وحالة بلا خيارات، والأسهم، ومنع إرسالين، والاحتفاظ بالنص عند رفض الإرسال، والملخص المستعاد. تغيرت توقعات قائمة الأسئلة المتعددة لتعرض خطوة واحدة، وتوقعات سطر Other وحروفه لأنه أزيل. اختبار تنسيق `answerText` القديم محفوظ.
- `AssistantPanel.test.tsx`: اختبار السؤال الواحد واختبار حفظ التنوين العربي أصبحا يضغطان Send بدل الإرسال بمجرد الاختيار. اختبارا إرسال جميع الاختيارات وإجابة السؤال المفتوح من الـ Composer دُمجا في اختبار خطوات يجمع الاختيارات والنص داخل السؤال في رسالة واحدة، مع الاحتفاظ بفحص تبديل الاختيار. اختبارات نية الصعود أصبحت تتوقع زرًا مخفيًا قبل الحركة، وتظل تتحقق من توقف المتابعة. أضيف اختبارا طول الخيط واختبار العربية مع محتوى إنجليزي والرجوع إلى النهاية وعدم وجود الزر داخل النص.
- `notices.test.tsx`: تغير محدد النص إلى بطاقة التطبيق بدل `data-title` الخاص بـ Sonner. أضيف فحص البطاقة وزر الإغلاق لكل الأنواع وغياب `[data-icon]` و `[data-close-button]`، ومنع تكديس الازدحام باللغتين وربط Stop بالرسم الأصلي.
- `useStickToBottom.test.tsx`: اختبار جديد لتغير الحجم والمحتوى بعد توقف المتابعة، ثم العودة للنهاية.
- `useAssistantWiring.test.tsx`: ازدحام التحديث التلقائي صامت ويُعاد، والفشل الحقيقي ظاهر، وتعديل ميزان يلغي عرض التراجع القديم حتى عند تعذر التحديث.
- `useAutosave.test.tsx`: اختبارات جديدة لرمزي الازدحام وإعادة المحاولة، مع اختبار مقابل لفشل الحفظ الحقيقي الذي يظهر مرة ويعطّل الحفظ التلقائي.
- `PackCheckCard.test.tsx` و `RecognitionPanel.test.tsx` و `SplitPane.test.tsx`: قراءة خلفية مزدحمة بلا خطأ ظاهر ثم نجاحها عند التغيير التالي.
- `workspaceIpc.test.ts` و `pointerMove.test.tsx`: لا توجد حلقة إعادة محاولة للتحويم المقفول، ولا تنبيه منه، والحركة التالية تعيد المحاولة. اختبار انتظار الالتقاط الصريح محفوظ.
- `commands.rs`: أضيف `workspace_busy_background_reads_use_committed_snapshots` لقراءة البيانات المنشورة أثناء إمساك قفل الجلسة وتجاوز الحفظ التلقائي للرسم المقفول. أضيفت أوامر التقرير والمجاميع إلى مسجل IPC الاختباري. اختبار `workspace_busy_tool_keeps_other_drawing_ipc_interactive` لم يتغير.
- لم يُحذف أو يُعطّل أي اختبار آخر. ملفات `useDrawings.test.tsx` و `useSheets.test.tsx` و `App.test.tsx` شُغلت دون تعديل.

## حدود التحقق والقرارات المتبقية

- اختبارات Rust المذكورة موجودة داخل وحدة `commands.rs` في مكتبة desktop. تشغيلها يحتاج `cargo test -p qiyas-desktop --lib ...`، بينما الطلب سمح بـ `--test all` فقط أو `cargo check`. لذلك لم تُشغّل اختبارات Rust، ولا يُدّعى التحقق التنفيذي منها؛ فحص crate نفسه نجح.
- لم يُنفذ الاختبار الحي الكبير أو فحص بصري داخل النافذة، التزامًا بعدم فتح نافذة أو متصفح.
- مسار زر آخر الرسائل في المصدر كان يستخدم ترجمة الواجهة أصلًا. لم يُثبت سبب ظهور الإنجليزية في الجلسة القديمة؛ الاختبار الجديد يثبت بقاء الزر عربيًا مع محتوى إنجليزي، ومع اللغة والاتجاه الصريحين الآن.
- لا توجد قرارات مطلوبة من المؤسس. العمل متروك دون commit أو stage أو push، و CLAUDE.md وملفات core و samples و .local لم تُعدّل.
