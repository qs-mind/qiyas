# Phase 23: trust

The generic read and the window use the same read-only explanation resolver. Generated items
include their dimension lines, drawing handles/sheets, elements, recognition rules/evidence,
measurement rules/citations and confidence. Imported and manual quantities disclose that no
rule is implied. Project contributions snapshot explanations at the time of their run and retain
drawing identity, including when two drawings use the same CAD handles.

Selectors: `generated:<code>`, `boq:<code>`, `boq-row:<index>`, `takeoff:<id>`,
`dimension:<decimal object handle>:<rule>`. A project explanation supplies `project` with its
`.qss` path and `item` with its unique code or `project:<index>`.

Confidence is the minimum of the measurement rule and recognition confidences for contributing
sources, including deduction decisions. BOQ and project aggregation retain the minimum. Missing
confidence and unrecognised/manual evidence use 0.5. These are conservative interpretation
scores, not claimed probabilities. Bands are low [0,0.6), medium [0.6,0.9), high [0.9,1].
Reports sort lowest first, retain counts and never introduce a mandatory review step.

Desktop sessions retain Mizan's working sheet independently. Generic tools enter that sheet
under the session lock and restore the visible sheet on success, error or panic. Window sheet
commands and scripts remain available during a turn; automatic view events do not steal the
camera or sheet. Reveal animations run only when that working sheet is visible. Explicit Show actions select and fit
the requested evidence sheet. Drawing-tab
replacement still cancels the old turn; history undo remains guarded during a turn.

Calibration uses the existing benchmark correctness tolerances. Matched items are scored in
their submitted confidence band; unmatched extras fail. Valid duplicate aggregate totals are
excluded, and missing predictions have no confidence. Each case and the aggregate report retain
band counts and observed pass rates. Empty bands have no observed rate. No truth enters confidence
prediction. Shared-rule autonomy remains an engine diagnostic, not a live MIZAN ALONE result.

No dependencies, trade rules, rates, model calls, or paid services were added.
